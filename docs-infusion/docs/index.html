Fluid Integration Language

This page documents the Fluid Integration Language (IL), the configuration language through which Fluid Infusion 6 components are defined, composed and wired together as an integration domain . It is implemented in FluidIL.js on top of the reactive primitive fluid.cell , whose semantics (signals, effects, unavailable values , deferred stabilization) it inherits throughout. The raw markdown underlying these docs is available on GitHub , suitable for direct ingestion by your friendly local neighbourhood intelligence.

Potentia Transmission Format

This page documents the Potentia Transmission Format (PTF), a plain-text document format which captures everything required to reconstruct a live Fluid Infusion 6 component somewhere else: in another page, another application or another user’s session. It is implemented in FluidPTF.js . It transmits a component’s layers , its potentia and the contents of its live layer . The raw markdown underlying these docs is available on GitHub , suitable for direct ingestion by your friendly local neighbourhood intelligence.

Fluid Signals background

This page contains background information motivating the design of fluid.cell , the reactive primitive built to support Infusion 6, explaining how it differs from traditional reactive libraries. There are also API docs for fluid.cell and also a more extended essay explaining its goals in the context of a malleable substrate. I chose the name “cell”, rather than “signal” which is more common in the 2020s JavaScript reactive community, in honour of 3 traditions: Spreadsheet cells, which are the public’s primeval grounding in reactivity.

Fluid tldraw integration

This page documents how Fluid Infusion 6 components are hosted as widgets on a tldraw canvas: how a layer marks itself as a widget, what the canvas tells a widget about where it is hosted, and how widgets are nested and composed. It builds on Fluid View (views, and sharing them between components) and on the Fluid Integration Language (layers, references, $linkage , $bindable ). The layers marking and receiving hosting, fluid.topLevelWidget and fluid.topLevelWidgetView , are part of the framework, in FluidView.js , and say nothing about tldraw.
